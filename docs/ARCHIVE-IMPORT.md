# 已有归档进入新核读任务

使用 ingest-archive JOB_ID MANIFEST，只接受解包后的 assets/<post_id>/manifest.json。先用 add 将同一规范首帖URL入队；完整证据目录须在本地可读。

该命令沿用普通严格 archive.verify_archive，不使用历史兼容例外。它检查帖子身份、SHA-256、字节数、路径、MIME、预算及首楼来源，然后保留原manifest和证据字节进入新快照。原capture_method/captured_at保持原值，这不代表重新采集。

复制在租约下完成，验证成功后才提交数据库指针。重复快照不新增文件；原已接受状态保留。变更快照保留旧分析版本，等待新工作包。错误或租约失效不能提交不完整快照，已有分析不被覆盖。

原历史兼容归档若含二级报告、特定首楼补充文字或非普通匹配文本，可能不符合此入口。使用import-legacy保留历史层，不要改manifest、伪造完整网页或跳过验证。只有明确支持的来源规则才能增加新的核读入口。

本次真实971353测试使用原先已有归档，未改一个原文件。新的助手核读日志记录本次实际阅读；原证据捕获日期和本次核读日期分别保存。
