# VPS 测评索引

中文静态公开目录，100 篇 NodeSeek 资料及 108 条结构化对象。对象数不等于独立机器数。

## 数据与来源
- dist/data.json：原始公开结构化快照，保留 null、原单位和来源。
- dist/enrichment.json：历史价格及 CPU 跑分，按 itemId 精确关联。
- dist/image-evidence.json：复用已有图片核读记录；41 条对象，未重新检查原图像素。
- dist/filter-spec.json：按用户 Excel 核验的 53 项字段、9 个分组，不含示例测量值或工作簿私有元数据。
- 公开包无原帖全文、原图、原图 URL、作者、IP 地址或推广链接。

## 筛选口径
- CPU / 内存 / 硬盘默认严格大于，可显式切换至少（≥）。未知不记为零。
- 分类同组 OR、跨组 AND；线路同一观测精确匹配协议、方向、运营商和标签。
- 付款周期只展示。按明确周期折算月均价，不表示实际可月付；各币种独立区间，不换汇。
- 价格遵循刀=USD、数值旁 O/o/欧=EUR、缺币种的明确价格默认 USD，保留依据与原始价格。
- Geekbench 5/6、单核/多核分四个独立区间；只筛主观测。
- 时间只用已确认北京时间的同一报告同时匹配日期与时间段。
- 图片 FIO 按明确负载/队列/单位检索，非受控性能排名。
- TCPQuality 延迟、范围、有效测点均值、RTT 和监控快照不作为通用平均 Ping。
- 42 项规范字段已有可筛数据，付款周期1项仅显示，10项待补（2026-10-08两帖复核后）。

纯静态 HTML/CSS/JavaScript，发布目录 dist。无登录、支付、跟踪、自动采集或后台任务。
